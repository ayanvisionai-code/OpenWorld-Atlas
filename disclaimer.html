4. Cheat code authenticity policy

Cheat inputs are community-documented, not official Rockstar material. Our labeling rules:

  • ✅ "Input known" — the exact input sequence is published by a named source (currently PowerPyx's complete GTA 6 cheat guide, which is the primary source major outlets credit). Every such code is attributed on the page.
  • ⏳ "Not yet discovered" — the cheat and its unlock condition are confirmed, but no attributed input exists. We never invent, guess, or republish unattributed inputs.
  • Using cheats disables saving and trophies for that session — we say so on every relevant page so readers aren't surprised.
  • We actively warn users away from fake "money generators", cheat apps and APKs, which are scams and/or malware.
  • If Rockstar or Take-Two publishes an official cheat reference or asks for adjustments, we will comply and update immediately.
